🚪 Gatemate: Your Deliveries, Our Community

Gatemate is a web application built to solve a common hostel problem: procrastination in picking up food and parcel deliveries from the main gate. This platform encourages a community-driven solution where students help each other, earn points, and gain priority in return.

💡 Idea Overview
Hostel students often delay picking up their deliveries due to study schedules, bad weather, or simply laziness. Gatemate connects students who are already heading to the main gate with those who need help collecting their orders — creating a win-win environment.

🎯 Key Features
✅ Student Login with College Email
  Only verified students (e.g., @vitstudent.ac.in) can access the app via Firebase Authentication.

📦 Delivery Request System
  Students can post parcel pickup requests with details like time, location, and payment type (COD or Prepaid).

🤝 Helper Matching
  Students near the gate can accept delivery requests and earn points for successful deliveries.

🎯 Point & Priority System
  Earn 1 point per successful delivery.
  Higher points = higher priority in future delivery requests.

⚖️ 2:1 Fair Use Ratio
  A student must deliver 1 order to be eligible to receive 2.
  Encourages participation and prevents freeloading.

💰 Payment Type Indicator
  Clarifies whether the order is COD or Prepaid for the helper.

🛒 Find Cart Partner (e.g., Blinkit)
  Students can share delivery carts to reduce fees and split costs.

🧠 How It Works
1. Login
   Student logs in using their official student email ID.
2. Request Delivery
   Fill a form with order details, pickup time, payment type, and instructions.
3. Accept Delivery
   Students heading to the gate browse open requests and accept any suitable task.
4. Delivery & Confirmation
   Helper picks up and delivers the order.
   Requester confirms receipt. Both parties earn/adjust points.
5. Ratio & Points Enforcement
   System maintains a 2:1 delivery-to-request ratio per user.
   Points updated after each transaction.
